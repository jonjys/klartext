# Klartext

AI som skriver svenska dokument folk fryser på. Personligt brev, överklagande, samboavtal, reklamation, skuldebrev och fler. 79–199 kr styck, eller Pro 249 kr/mån.

Utkastet är gratis. Hela texten efter betalning via Stripe.

**Detta är inte juridisk rådgivning.**

## Produkten

- 12 dokumenttyper
- AI-skrivare (utkast → betala → hela texten)
- Rådgivaren (support-agent)
- Guider för SEO
- Stripe Payment Links (live, SEK)

## Live Stripe

Produkter och betal-länkar ligger på kontot AI Commerce OS.
